# LVN Engenharia - Site Institucional

Site profissional para a LVN Engenharia, empresa de engenharia civil.

## Stack

- React 18
- TypeScript
- Vite
- TailwindCSS
- React Router
- Framer Motion

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`.

## Build para produção

```bash
npm run build
npm run preview
```

## Estrutura

- `/src/components` – Componentes reutilizáveis (Navbar, Footer, Hero, etc.)
- `/src/pages` – Páginas (Home, Sobre, Serviços, Portfólio, Contato)
- `/src/data` – Dados (serviços, portfólio)
- `/src/styles` – Estilos globais
